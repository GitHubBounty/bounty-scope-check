# Security

## This repository is not a bounty target

Reports about this repository, its contents, or its configuration are out of scope
and will be closed. In-scope products are listed at
<https://bounty.github.com/targets>.

## Reporting a vulnerability in a GitHub product

Submit it to the GitHub Security Bug Bounty program on HackerOne:

**<https://hackerone.com/github>**

Program rules, scope, and legal safe harbor: <https://bounty.github.com/rules>

**Do not** open an issue or pull request here, and do not include vulnerability
details in any public channel in this repository. Issues are disabled for this
reason.

## Reporting a problem with this skill

If the skill content is wrong, out of date, or contradicts
<https://bounty.github.com>, email `bounty@github.com` with the discrepancy.

If you believe the skill content itself has been tampered with, email
`bounty@github.com` immediately and do not run it.
