# Contributing

**Pull requests are not accepted in this repository.**

The contents of this repository are generated from <https://bounty.github.com>,
which is the authoritative source. Pull requests opened here will be closed
without review.

## If something is wrong

Email `bounty@github.com` and describe the discrepancy — which file, what it says,
and what you believe it should say.

## If you have found a vulnerability

Submit it to <https://hackerone.com/github>. Do not include vulnerability details
in a pull request, a commit message, or any other public channel in this
repository. See [SECURITY.md](SECURITY.md).
