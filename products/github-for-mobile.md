# GitHub Mobile

Canonical page: https://bounty.github.com/targets/github-for-mobile

## Synopsis

Bring GitHub collaboration tools to your small screens with [GitHub Mobile](https://github.com/mobile).

Please see [our severity guidelines](https://bounty.github.com/rewards) for more information about how severities are calculated.

## Focus areas

Findings of this kind are the ones the program most wants for this product.

* Authentication and credential handling
* Mobile specific APIs
* Any protocol handlers, such as `github://`

## Out of scope

Explicitly excluded for this product.

* Push notifications are handled by a third-party system and are _not_ in-scope for the GitHub bounty program.

## Known ineligible submissions

These have been reported before and are not eligible. Check this list carefully.

### On-screen data is not hidden when backgrounding the app

The GitHub Mobile apps do not clear on-screen data when they are backgrounded. This is by design and does not present a security risk.

### No jailbreak detection

The GitHub Mobile apps do not attempt to detect jailbreaked devices. This is by design and does not present a security risk.
