# GitHub Education

Canonical page: https://bounty.github.com/targets/github-education

## Synopsis

GitHub Education offers a variety of tools to help educators and researchers work more effectively inside and outside of the classroom. More details are available at [https://github.com/education](https://github.com/education).

## Out of scope

Explicitly excluded for this product.

* The [GitHub Education Community discussions](https://github.com/orgs/community/discussions/categories/github-education) are not in-scope and ineligible for rewards.
* [GitHub Classroom](https://github.com/orgs/community/discussions/205975) was decommissioned on August 28, 2026. Classroom, the Classroom Assistant application, and any remaining Classroom endpoints are out-of-scope and ineligible for rewards.
