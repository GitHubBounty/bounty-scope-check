# In-scope products and domains

The product pages listed in `SKILL.md` establish product scope. This reference defines domain scope and additional standalone products. A GitHub-owned domain not listed here is out of scope. A product is out of scope only if it has neither a listed product page nor an entry here.

GitHub runs a number of services. Product pages in the [target directory](https://bounty.github.com/targets) define in-scope products, while the list below defines in-scope domains and additional standalone products. A GitHub-owned domain not listed below, or a product that has neither a target page nor an entry below, is *not* in scope, *not* eligible for rewards, and *not* covered by [our legal safe harbor](https://bounty.github.com/rules#legal_safe_harbor).

## github.com

This is our main domain for hosting user-facing GitHub services.

All subdomains of `github.com` are in scope, *except* the following, which are out of scope:

* `blog.github.com`
* `community.github.com`
* `email.enterprise.github.com`
* `email.finance.github.com`
* `email.staging.finance.github.com`
* `email.support.github.com`
* `email.verify.github.com`
* `google7650dcf6146f04d8.github.com`
* `k1._domainkey.github.com`
* `k1._domainkey.mcmail.github.com`
* `mcmail.github.com`
* `resources.github.com`
* `*.resources.github.com`
* `sgmail.github.com`
* `*.sgmail.github.com`
* `shop.github.com`
* `smtp.github.com`
* `*.smtp.github.com`
* `livesend.github.com`

## githubassets.com

This is our domain for hosting static assets.

All subdomains of `githubassets.com` are in scope.

## githubusercontent.com

This is our domain for hosting and rendering users’ data.

All subdomains of `githubusercontent.com` are in scope.

## githubapp.com

This is our domain for hosting employee-facing services.

All subdomains of `githubapp.com` are in scope, *except* the following, which are out of scope:

* `atom-io.githubapp.com`
* `atom-io-staging.githubapp.com`
* `email.enterprise-staging.githubapp.com`
* `email.haystack.githubapp.com`
* `reply.githubapp.com`

## githubwebhooks.net

This is our domain for receiving webhooks for employee-facing services.

All subdomains of `githubwebhooks.net` are in scope.

## github.net

This is our domain for hosting GitHub’s internal production services. Many of these services are not accessible from outside our internal network.

All subdomains of `github.net` are in scope.

## npmjs.com

This is the domain for npm’s public-facing websites.

All subdomains of `npmjs.com` are in scope.

## npmjs.org

This is the domain for npm’s registry, public-facing databases, and APIs.

All subdomains of `npmjs.org` are in scope.

## GitHub CLI

GitHub CLI is an open source command line tool for working with your GitHub.com account.

This product is in scope.

## GitHub Desktop

GitHub Desktop is an open-source Electron-based app for working with your GitHub.com or GitHub Enterprise account.

This product is in scope.

## GitHub Copilot App

GitHub Copilot App is an agent-native desktop experience for managing software work from idea to pull request.

This product is in scope.

## GitHub Mobile

GitHub Mobile is an app to bring GitHub collaboration tools to your small screens.

This product is in scope.

## npm CLI

npm CLI is the command line client for installing and publishing packages with npm registries.

This product is in scope.

## GitHub Enterprise Server

GitHub Enterprise Server is the on-premise version of GitHub Enterprise.

This product is in scope.

## GitHub Enterprise Cloud

GitHub Enterprise Cloud is the cloud-hosted version of GitHub Enterprise.

This product is in scope.
